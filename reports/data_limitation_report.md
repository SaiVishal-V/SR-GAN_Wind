## 2. Block Averaging Artifacts

The LR input is generated by **block averaging** the HR field in 4×4 blocks. This has specific implications:

### 2.1 Gradient Suppression

Block averaging is equivalent to a box filter (uniform kernel) followed by decimation. The box filter:
- **Aggressively suppresses high-frequency gradients** — wind fronts, eddies, and mesoscale structures are smoothed
- **Introduces ringing artifacts** in the frequency domain due to the sinc-like frequency response of the box filter
- **Quantizes** the gradient information into 4×4 block boundaries

**Measured evidence**:
- HR value range: [-2.161, 8.418] (normalized)
- LR value range: [-1.601, 5.979] (normalized)
- HR std (ocean): 0.873
- LR std: 0.751
- **Compression ratio**: 0.751/0.873 = 0.86 — LR retains 86% of HR variance

The 14% variance reduction is moderate, suggesting block averaging preserves bulk statistics reasonably well but smooths local variations.

### 2.2 Spectral Information Loss

FFT analysis of timestep 0:
- HR radial spectrum: peak 85.7 dB, noise floor 41.9 dB, dynamic range 43.8 dB
- LR has fundamentally lower spatial resolution (80×140 vs 320×560)

The block averaging acts as a low-pass filter with cutoff at the Nyquist frequency of the LR grid. All spatial information above this frequency is **permanently lost** and must be hallucinated by the SR model.

**Critical implication**: The SR model cannot recover true high-frequency details — it can only learn the statistical relationship between LR patterns and HR textures. This sets a theoretical upper bound on achievable SR quality.

### 2.3 Comparison with Alternative LR Generation Methods

| Method | Characteristics | Expected SR Quality |
|--------|----------------|-------------------|
| **Block averaging** (current) | Box filter, sinc spectrum, sharp cutoff | Baseline |
| Bicubic downsampling | Smooth kernel, natural roll-off | Slightly better (less aliasing) |
| Area downsampling | Similar to block average but smoother | Similar |
| Gaussian + decimation | Smooth Gaussian kernel, no ringing | Best (most natural LR) |

**Recommendation**: The current block-averaged LR is the **official dataset** and must remain the primary input (dataset protection rule). Alternative methods should only be explored in Tier 3 (E12) as a research comparison.

## 3. Ocean Mask Analysis

### Static Ocean Mask (`hr_ocean_mask`)
- Shape: (320, 560)
- Ocean fraction: **57.83%** (103,633 pixels)
- Land fraction: 42.17% (75,567 pixels)

### LR Ocean Fraction (`lr_ocean_fraction`)
- Shape: (80, 140)
- Fully ocean (≥0.99): 55.05% of LR pixels
- Fully land (<0.01): 39.75% of LR pixels
- Mixed (coastline): 5.20% of LR pixels

**Implication**: ~40% of the LR input is fill values (land). The model must learn to ignore these regions. The current pipeline correctly replaces fill values with 0.0 and uses the ocean mask to restrict loss computation.

### Observed Mask (`observed_mask`)
- Shape: **(392, 321, 561)** — per-timestep, on the original grid (not HR/LR grid)
- Values: binary {0, 1}
- Mean coverage: **36.27%**

**Critical finding**: The observed mask is on the **original grid** (321×561), not the HR grid (320×560). It needs to be cropped to (320, 560) to align with `hr_ocean_mask` for use in evaluation.

**Impact on evaluation**: Only 36.3% of ocean pixels have actual satellite observations. The remaining ~21.5% of ocean pixels (57.8% - 36.3%) contain gap-filled values. Observed-only evaluation will provide a more reliable quality assessment than evaluating all ocean pixels (which include gap-filled targets).

## 4. Fill Value Analysis

### Constant Fill Pattern
- LR fill fraction: **39.75%** (constant across all timesteps)
- HR fill fraction: **42.17%** (constant across all timesteps)

The fill fraction is **identical** across all timesteps, meaning the fill pattern corresponds exactly to the land mask — there are no missing ocean pixels in the HR target. This is expected because the HR target uses `wind_speed_filled` (gap-filled).

**Implication**: The training target is always complete over ocean. However, the satellite observation quality varies by timestep (observed_mask coverage varies), which means some ocean pixels are gap-filled reconstructions rather than direct observations. Evaluation on observed-only pixels is therefore more scientifically meaningful.

## 6. Theoretical SR Quality Bound

Given block averaging as the LR generation method:

1. **Information-theoretic limit**: The LR contains exactly 80×140 = 11,200 independent spatial samples per timestep. The HR target has 103,633 ocean pixels. The SR model must reconstruct a 9.2× information expansion over ocean — this is well within the capability of learned SR methods because wind fields have strong spatial correlations.

2. **Frequency limit**: All spatial frequencies above the LR Nyquist (40 cycles/degree in latitude, 70 cycles/degree in longitude) are permanently lost. The SR model learns to predict plausible high-frequency content from low-frequency patterns.

3. **Quality ceiling**: For block-averaged LR, the best achievable SR quality is bounded by:
   - The smoothness of the underlying wind field (smooth → easier SR)
   - The temporal consistency of spatial patterns (consistent → better learning)
   - The accuracy of gap-filling in the HR target (inaccurate fills → learning incorrect patterns)
